# Alex Rivera · Sample developer portfolio

Open `index.html` directly in a browser. The page uses local files and works without a server or build step. Section links and project notes work without JavaScript. JavaScript provides optional email copying where the browser exposes the Clipboard API.

Alex Rivera and the projects are fictional. The contact link uses `alex@example.com` as a placeholder.

The sunset skyline was drawn for this example using raster shapes and gradients. The project covers are original CSS artwork. The page uses system fonts and includes no third-party media or game assets. This is an independent design study with no Rockstar Games affiliation.
